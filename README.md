# CodeBuddy 🤖

An AI-powered programming chatbot built with React, Spring Boot, Spring AI, and Ollama.

## 🚀 Features
- Interactive AI chat interface for programming questions.
- Built with React on the frontend.
- Powered by Spring Boot & Spring AI backend integrated with local Ollama (`llama3`).

## 🛠️ Tech Stack
- **Frontend:** React, Vite
- **Backend:** Java, Spring Boot, Spring AI
- **LLM Engine:** Ollama

## 🔧 Prerequisites
- Java 17+
- Node.js & npm
- Ollama installed and running locally (`ollama run llama3`)
